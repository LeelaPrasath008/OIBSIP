# Unemployment Analysis with Python

## Project Overview

This project explores unemployment trends in India using Python. It analyzes regional differences, monthly unemployment patterns, relationships between employment indicators, and changes in unemployment averages before and after the onset of the COVID-19 pandemic.

## Objectives

* Analyze average unemployment rates across regions.
* Examine monthly unemployment trends over time.
* Compare unemployment trends across selected Indian states.
* Identify the ten regions with the highest average unemployment rates.
* Explore correlations between unemployment, estimated employment, and labour force participation.
* Compare average unemployment rates before and from March 2020 onward.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset

**Dataset:** Unemployment in India

The dataset contains regional and time-based unemployment information, including estimated unemployment rates, estimated employment, and estimated labour participation rates.

**Source:** [Kaggle — Unemployment in India](https://www.kaggle.com/datasets/gokulrajkmv/unemployment-in-india)

The CSV file used for this analysis is included in this project folder.

## Analysis Performed

1. **Data Loading and Inspection:** Loaded the dataset and examined its dimensions, columns, data types, and missing values.
2. **Data Cleaning:** Standardized column names, converted dates and numerical columns, handled missing values in essential columns, and sorted records chronologically.
3. **Regional Analysis:** Calculated and visualized average unemployment rates by region.
4. **Monthly Trends:** Examined changes in average unemployment rates over time.
5. **State Comparison:** Compared unemployment trends across selected states.
6. **Top 10 Regions:** Identified the regions with the highest average unemployment rates.
7. **Correlation Analysis:** Visualized relationships between unemployment, estimated employment, and labour participation.
8. **COVID-19 Period Comparison:** Compared average unemployment rates before March 2020 and from March 2020 onward.

## How to Run the Project

1. Download or clone this repository.

2. Ensure Python is installed.

3. Install the required libraries:

   ```bash
   pip install pandas matplotlib seaborn jupyter
   ```

4. Open a terminal in the project folder.

5. Launch Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

6. Open `Unemployment_Analysis.ipynb`.

7. Run the notebook cells in order.

## Key Insights

The notebook uses statistical summaries and visualizations to examine regional differences, monthly changes, and relationships between employment indicators. The specific findings should be interpreted from the results generated by running the notebook.

The pre- and post-March 2020 comparison is descriptive and does not establish that COVID-19 alone caused changes in unemployment.

## Conclusion

This project demonstrates how Python-based data analysis can be used to explore unemployment patterns in India. Pandas supports data preparation and analysis, while Matplotlib and Seaborn help communicate the findings through visualizations.
