# Oasis Infobyte Data Science Internship

## About the Internship

This repository contains the projects I completed as part of my **Data Science Internship at Oasis Infobyte (OIBSIP)**. The internship provided practical experience in Python programming, data analysis, data visualization, data preprocessing, and machine learning through real-world datasets and hands-on projects.

## Projects Completed

### Task 1: Iris Flower Classification

**Objective:** Build a machine learning model to classify iris flowers into different species using their measurements.

- Explored the Iris dataset and analyzed its features.
- Performed exploratory data analysis (EDA) using visualizations.
- Trained and evaluated Logistic Regression and K-Nearest Neighbors (KNN) classifiers.
- Compared model performance using accuracy.

**Technologies:** Python, Pandas, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook.

**Project folder:** `DataScience-Task1-IrisClassification/`

### Task 2: Unemployment Analysis with Python

**Objective:** Analyze unemployment trends in India, with attention to changes during the COVID-19 period.

- Explored and cleaned unemployment-related data.
- Analyzed unemployment trends and variations across regions.
- Used data visualization to identify patterns and changes over time.
- Developed visual insights to better understand unemployment trends.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook.

**Project folder:** `DataScience-Task2-UnemploymentAnalysis/`

### Task 4: Email Spam Detection with Machine Learning

**Objective:** Develop a text classification system that distinguishes spam messages from legitimate messages.

- Preprocessed text data using basic text-cleaning techniques.
- Converted text into numerical features using TF-IDF.
- Trained Multinomial Naive Bayes and Logistic Regression classifiers.
- Evaluated the models using accuracy, precision, recall, F1-score, and confusion matrices.
- Used word clouds to visualize common words in spam and legitimate messages.

**Technologies:** Python, Pandas, Scikit-learn, Matplotlib, Seaborn, WordCloud, Jupyter Notebook.

**Project folder:** `DataScience-Task4-SpamDetection/`

*Note: The dataset used for this project is the SMS Spam Collection dataset. Although the task is titled Email Spam Detection, the dataset contains SMS messages.*

Dataset: [UCI SMS Spam Collection](https://archive.ics.uci.edu/dataset/228/sms+spam+collection)
